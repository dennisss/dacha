# Workbench

This doc contains the design for a 1000mm width x 600mm deep x 1000mm tall workbench meant for doing standing work or for placing down 3D printers or desktop CNCs.

## BOM

Below is a list of all items needed to build one table with length 'L' and depth 'D'

For a 1000mm x 600mm surface:

- 39-3/8" Width x 23 5/8" Depth

For a 800mm x 600mm surface

- 31 1/2" Width x 23 5/8" Depth

For a 500mm x 600mm surface

- 19 5/8" Width x 23 5/8" Depth

**Aluminum Extrusions**:

For all of these, use Misumi 8 series Base 40 (HFS8-4040)

- Top
    - 2 x 1000mm (Length mm) (HFS8-4040-XXX)
    - 2 x 520mm (Width - 80mm) (HFS8-4040-XXX)
- Feet
    - 4 x 930mm (HFS8-4040-XXX)
- 4 x Corner bracket (HBLFSNF8-SET)
    - For connecting X/Y axes of the Top surface
- 4 x L Bracket (HPTLN8-SET)
    - For connecting X beams with Z beams (feet)
- 8 x Corner bracket (HBLFSNF8-SET)
    - For connecting foot to X/Y beams for extra rigidity.

Each shelf (double these for two shelves)
- 2 x 920mm (Length - 80mm) (HFS8-4040-XXX)
- 2 x 520mm (Width - 80mm) (HFS8-4040-XXX)
- 4 x T Bracket (HPTTS8-SET)
- 4 x Corner Bracket (HBLFSNF8-SET)

For connecting two tables together:

- 4 x Square 4-hole bracket (HPTSD8-SET)


## Assembly

### Long Side Assembly

(do these steps twice to get two flat sides of the table)

Items:

- 1 x 1000mm 40x40 extrusion (top beam)
- 2 x 930mm 40x40 extrusion (legs)
- 2 x 920mm 40x40 extrusion (middle / shelf beams)

Assemble as shown below:

- From the bottom of a top/shelf beam is 270mm of space to the top of the next beam below it.
    - So measure 270mm and 580mm from the top of the leg to get the right positions.
- Each shelf beam also has 2 nuts inserted on the reverse (non-visible) side. These will be used later.
- You will likely need 3 passes at tightening the bolts
    - Once to loosely tighten
    - Push all beams into flush/tight positions and tighten more
    - Perform a final tighten. Fully tighten the bolts as much as possible by hand. 


### Reverse Long Side Assembly

(do for both sides)

Attach corner brackets as shown below.

- The bolts+nuts with no beam attached yet should be very loose
- The bolts+nuts attached to a beam can be tightened to the point that the corner brackets don't move around.
    - Ensure that the corner bracket is close to the end of the beam but at least 2mm away from the end (shouldn't extend past the end of the beam).

### Add Center Beams

Add 6 x 920mm 40x40 extrusions as shown below.


### Attach the second long side


Attaching top board:

- M4 x 14mm machine screws with M4 T-Nuts to attach bracket to beams
    - Place brackets ~200mm from the edge of the table.
- Mark the holes
- Drill a pilot hole
- M4 x 10mm wood screws
