
This is a mesh addon for [this Voron V0.2r1 rear skirt](https://www.printables.com/model/533549-voron-02r1-rear-skirt-wkeystone
). I'd suggest to print this as a separate piece and glue it on with superglue. It leaves extra space around the keystone hole to avoid changing the fit of the base skirt.

Example print settings:

- 2 perimeters
- 30% infill
- 0 top/bottom solid layers
- Fill Pattern: Honeycomb
