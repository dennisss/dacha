# Galaxy Drink Coaster

5 color galaxy themed drink coaster.

This can be printed with any multi-color capable machine, though the provided 3mf is tuned for the Prusa XL. Since there as a ton of pieces, it is easiest to start with the 3mf rather than the STLs to avoid relabeling all the parts.

- Recommended colors:
    - Tool 1: Prusament Vanilla White PLA
    - Tool 2: Polymaker PolyTerra Matte Green PLA
    - Tool 3: Polymaker PolyTerra Matte Sapphire Blue
    - Tool 4: Polymaker PolyTerra Matte Yellow
    - Tool 5: Polymaker PolyTerra Matte Red
- Print Settings
    - Default 0.2mm layer height, 0.4 or 0.6mm nozzle.
    - Ironing on the top surface on parts.
        - Note that the interal 'islands' are split into two parts (a bottom and a single layer top cap). Only enable ironing for the top cap. 
    - If using a Prusa XL, place the purge tower behind the parts (closer to the tool rack) to minimize stringing from excess movements.
