# Rosewill 4U Sideways Frontpanel Bracket

This is a bracket with 4U server cases like the [Rosewill 4U Server (RSV-R4000U)](https://www.amazon.com/gp/product/B09HLCNKM3) which come with the front panel I/O mounted horizontally preventing insertion of a 3rd [Rosewill RSV 4 x 3.5-Inch HDD Cage RASA-11001](https://www.amazon.com/gp/product/B005FHHOXE). By mounting it sideways, you can fit 3 drive cages for a total of 12 HDDs in the case. 

- Print one of the each part (printer bed touching the flat surface) and stack them.
- Insert 2 x M4 Hex Nut into the main part.
- Use 2 x M3 10mm screws and M3 hex nuts to mount the front panel to the bracket
- Mount the bracket to the side of the compute case using 2 x M4 16mm screws (these will screw through the rack ears and handle).
