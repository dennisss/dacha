# Monitor on a Stick

A simple low profile VESA monitor arm.

This takes a 2020 aluminum extrusion and turns it into a simple VESA table monitor stand. Compared to most commercial stands, this will lock your monitor into a fixed angle/position and takes up a minimum amount of horizontal place over your table. While there is no angle adjustment, you can design spacers spacers to attach between the VESA mount and the monitor to add some tilt if needed.

Usage:

- Find a 20x20mm aluminimum extrusion beam : Recommended to be at least 500mm.
- Print 2 x `monitor-arm-vesa-half`
    - Recommended in PETG or stronger material.
    - High infill.
- Print 2 x `monitor-arm-table-clamp`
    - (minimum) Print in PETG with >50% infill
    - (recommended) Print in PCCF
        - 20% infill
        - 0.25mm layer height
        - 1.0 extrusion multiplier (default is 1.04 in prusa slicer)
            - I'd recommend printing 1 first and testing for a snug fit with the extrusion. You may need to decrease this if the part doesn't fit.
- Slide both `monitor-arm-table-clamp` parts onto the aluminum extrusion with the flat sides facing each other.
- Align the 'top' one with the rough final position
- Fully fasten the top clamp to the aluminum extrusion using:
    - 2 x M4 T-Nut (Pre-assembly type)
    - 2 x M4 8mm pan head machine screw
    - Fully tighen the screws
- Repeat for the bottom clamp halt except don't tighten the screws (the clamp bottom should still be able to move).
- Connect both clamp halfs together using:
    - 2 x M4 nut
    - 4 x M4 Washer (9mm OD)
    - 2 x M4 40mm machine screw (if attaching to a 1 inch thick table)
    - Don't fully tighten. We need to leave space to slide the table between the clamp halves.
- Attach the VESA mount parts to the monitor using:
    - 4 x M4 12mm machine screws
    - 4 x M4 12mm washer
- Attach the monitor with VESA mount parts to the aluminum extrusion using
    - 4 x M4 8mm machine screws
    - 4 x M4 T-Nut (Pre-assembly type)
- Lift the assembly and slide the clamp halves over the side of a table.
- Tighten the long M4 40mm screws to clamp the halves together.
- If you want to attach the clamps to a wood table,
    - Use 2 x M4 10mm wood screws to screw the bottom clamp into the table.
- Tighten the M4 8mm screws attaching the bottom clamp to the aluminum extrusion.
