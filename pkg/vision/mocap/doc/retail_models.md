# Optical Motion Capture : Retail Model Specs

This page documents exactly what parts are included in each purchase from "Made By Dennis".

## Beta

The following items are included in purchases:

- 1 x Wand Kit (one per customer)
    - All the individual parts needed to build one [4 point wand](./wand.md).
    - This needs to be assembled using a standard set of metric hex allen wrenches
- 1 x Lens Focus Tool
    - The cameras come pre-focused at ~2 meters away but you may need to re-focus if there is a shift during shipping or you need a very different distance.
- N x Motion Capture Cameras
    - Raspberry Pi Compute Module 4 Lite (1GB RAM, no-eMMC, no WiFi)
    - Generic 4GB microSD card
    - Standard FOV IR ring
    - AR0234 camera sensor
        - 120 FPS at 1920 x 1200 (higher FPS will be available in software later at lower resolutions)
    - 3.9mm focal length M12 lens
        - <0.5% TV distortion
        - FOV: ~72 x 49 degrees.
    - Board Revisions
        - Compute R9 or R10
        - LED R6
        - AR0234 R2 
    - Range: > 5 meters
        - Requires sufficienctly large or bright markers
