Based on usb.org/sites/default/files/usbprint11a021811.pdf:

- "The Bulk OUT endpoint is used for transferring PDL and PCP data from the host to the printer:"
- "The Bulk IN endpoint is used to return any data generated by the PDL or PCP to the host. If the printer supports a
PCP, such as IEEE-1284.1 or IEEE-1284.4, this endpoint will return status or other printer-related information:"

- Use a "GET_DEVICE_ID" request to figure out capabilities (will be a "IEEE 1284 string")
